# Твой ход 0 · Собери рабочее место

**Это не занятие.** Это то, что ты делаешь до первого занятия, у себя, сам.

**Зачем.** Чтобы первое занятие не ушло на установку. Оно одно, оно короткое, и жалко тратить его на скачивание.

**Сколько это займёт.** 20–40 минут, и большая часть — ожидание, пока качается. Можно уйти за чаем.

**Что у тебя будет в конце.** Готовое рабочее место и одна строчка, которую ты пришлёшь тренеру.

---

## Что вообще происходит

На твоём компьютере появятся три вещи:

- **Ubuntu** — Linux внутри Windows. Там живёт работа.
- **Редактор** — VS Code. Там ты видишь свой проект и правишь его.
- **Claude Code** — ИИ, который делает работу. Он будет и в редакторе, и в терминале.

Ставить руками ты это не будешь. Для этого есть два скрипта:

| Скрипт | Что делает |
| --- | --- |
| `setup.sh` | **ставит** |
| `check-setup.sh` | **смотрит** и говорит, готово или нет |

**Ни один из них ничего не удаляет.** А `check-setup.sh` вообще ничего не меняет — только смотрит.

---

## 1 · Открой Ubuntu

Пуск → набери `Ubuntu` → Enter. Откроется чёрное окно с текстом. Это **терминал** — место, где команды пишут словами, а не мышкой.

**Если Ubuntu нет.** Открой PowerShell от имени администратора и дай ему одну команду, потом перезагрузись:

```powershell
wsl --install -d Ubuntu
```

---

## 2 · Скачай репозиторий курса

**Репозиторий** — папка проекта, которая помнит все свои изменения. Этот — наш, курсовой.

```bash
git clone https://github.com/y-kolyada/b1bootcamp26.git
cd b1bootcamp26
```

**Если ответил `git: command not found`** — значит самого `git` ещё нет. Это единственное место во всей установке, где нужен пароль администратора, поэтому позови родителя:

```bash
sudo apt update && sudo apt install -y git
```

Потом повтори команды выше.

---

## 3 · Посмотри, что будет, ничего не меняя

```bash
./setup.sh --ru --dry-run
```

Он расскажет, что собирается сделать, и **не сделает ничего.** Прочитай. Так ты заранее знаешь, что он тронет, а что нет.

**Если ответил `Permission denied`** — запусти так:

```bash
bash setup.sh --ru --dry-run
```

и скажи об этом тренеру. **Это наша ошибка, не твоя** — файлу забыли разрешить запускаться.

---

## 4 · Запусти по-настоящему

```bash
./setup.sh --ru
```

Две вещи, которые он спросит:

- **Ник.** Латиницей, **без имени и фамилии.** Этим ником будут подписаны все твои изменения, и его видно всем в интернете — поэтому ник, а не имя.
- **Разрешение дописать строчку в настройки**, чтобы команды потом находились. Можно ответить `н`, тогда он просто скажет, что сделать самому.

В конце он покажет **длинную строку для Windows**, которая начинается на `\\wsl$\`. Скопируй её — она нужна на следующем шаге.

---

## 5 · Поставь редактор. Это делается в Windows, не в Ubuntu

VS Code — программа для Windows, и из Ubuntu её не поставить. Поэтому:

1. Пуск → `PowerShell` → Enter.
2. Вставь ту длинную строку и нажми Enter.
3. Дождись, пока поставится.

Потом **открой редактор и соедини его с Ubuntu:** `Ctrl+Shift+P` → набери `WSL: Connect to WSL` → Enter. Откроется новое окно редактора — оно уже внутри Ubuntu.

---

## 6 · Вернись в Ubuntu и запусти установщик ещё раз

```bash
./setup.sh --ru
```

**Второй запуск ничего не портит.** Что уже стоит — он оставит и так и скажет: `УЖЕ БЫЛО`. Теперь он доберётся до редактора и положит Claude Code внутрь него.

---

## 7 · Войди в Claude

```bash
claude
```

Дальше набери `/login` и войди **под аккаунтом родителя** — подписка его. Скрипт этого за тебя не делает и не должен.

Когда вошёл — выйди из `claude` (`Ctrl+C` дважды или `/exit`).

---

## 8 · Проверь и пришли одну строку

```bash
./check-setup.sh --ru
```

Он пройдёт по одиннадцати пунктам и по каждому скажет `ОК`, `НЕТ` или `ГЛЯНЬ`. Для каждого `НЕТ` — одна строка, что сделать.

В самом низу будет строка, которая начинается так:

```
BOOTCAMP-CHECK ok=... fail=... warn=... codes=... 2026-10-..
```

**Её и пришли тренеру.** Остальное присылать не надо — там может быть лишнее про твой компьютер.

---

## Что прислать, итого

**Две вещи.**

1. Ту строку `BOOTCAMP-CHECK`.
2. **Ответ на два вопроса, честно:**
   - Что здесь было непонятно? Назови номер шага.
   - Где ты застрял или сделал не то, что я имел в виду?

**Второе важнее первого.** Этот текст писал взрослый, а читают его семь человек твоего возраста. Автор — последний, кто может судить, понятно ли он написал: он знает, что хотел сказать, и читает свой замысел, а не свои слова. Поэтому судишь ты.

Если скажешь «шаг 5 — непонятно, какую строку копировать» — текст поменяется, и остальные шесть прочитают уже исправленный. Это не придирки, это и есть работа.

## Если застрял

**Напиши в Discord.** Не «я не смог» — а что ты сделал и что увидел. Лучше всего: скопируй последние строки из терминала.

Застрять на установке — нормально. Семь компьютеров, и ни один из них никто из нас не видел.

---

## Почему это называется «Твой ход»

Весь курс про одно: **ИИ исполняет — ты решаешь.** Ход всегда твой: что сделать, принять или вернуть. Поэтому не «задание» и не «домашняя работа», а ход — как в шахматах.

Их будет девять: этот, нулевой, и по одному на каждое занятие.
